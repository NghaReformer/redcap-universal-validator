Universal Field Validator Architecture

System architecture showing the client-side browser runtime, REDCap server integration hooks, dual-runtime parity validation engines, and the durable background scan subsystem.

BROWSER CLIENT RUNTIME

Live Feedback & Save Blocking

Injected on data-entry forms and survey pages. Evaluates user input as it is typed with zero external dependencies.

  • Immediate format and check-character validation (ISO 7064, Damm, Verhoeff, Luhn, etc.).
  • WCAG 2.2 AA live regions (role="status", aria-live="polite") with color-independent visual marks.
  • Save-blocker (blockSave: hard | confirm) preventing form submission without trapping read-only fields.

SERVER INTEGRATION & AUDIT

Dual-Runtime Parity & Privacy

REDCap module hooks enforce server-side validation on every save, mirroring the browser logic line-for-line.

  • Cross-runtime behavioral parity locked by 50+ test suites and shared test fixtures.
  • redcap_save_record hook catches API and Data Import Tool writes post-save.
  • Pseudonymized logging uses HMAC-SHA-256 with module-held secret to prevent data leakage.

DURABLE SCAN SUBSYSTEM

Historical & Batch Validation

Enterprise background scanner re-validates all historical data without hitting memory or execution timeouts.

  • State machine with bounded batches (WorkBudget) protecting against PHP fatal errors.
  • Dedicated uv_* database tables for idempotent checkpointing and finding storage.
  • CSV report streamer with role-based redaction, DAG isolation, and formula injection defense.
